# FullStack Open Course 2025
This repository gather all the exercises for [FullStack Open Course](https://fullstackopen.com).
The course is an introduction to modern web application development with JavaScript and its held at the [Department of Computer Science](https://www.helsinki.fi/en/faculty-science/faculty/computer-science) at the University of Helsinki in Spring 2023.

> ⚠️ **DISCLAIMER**
> 
> None of the concepts of this course are new to me, but after 4 years of management, I wanted to get a well structured refresh and a deeper look into server-side architecture.


## Tech stack
### Frontend
The main stack used are **HTML5**, **CSS3**, **JavaScript** and **ReactJS** on the client side.
### Backend
**Node.js**, **Express**, **GraphQL** with **REST APIs** architecture on the server side.

### Test coverage
For testing the application **End to End** both **Playwright** and **Cypress** will be explored.

### Deployment
THe development process is manage and automate with a **Continous Integration and Continous Deployment**, using **GitHub Actions**.
