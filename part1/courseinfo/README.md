# Course Info
Exercises from 1.1 to 1.5 are related to part 1 of the course.
The objective is to familiarize oneself with React and JavaScript basic concepts.

The different exercises have been separated by commit.
The final version of the App has three components: 
- Header
- Content
- Total

We assumed that we have the exact number of 3 exercises to pass as a prop; there is no need at this point in the course to use loops to render the DOM Elements.

## Run locally
From this root folder `./part1/courseinfo`, on the command line run

``` bash
npm install
npm run dev
```
The application is visible in the browser on the default port of http://localhost:5173/
